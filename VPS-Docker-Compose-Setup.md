# VPS Docker Compose 部署配置 ## 1. VPS 准备 SSH 密钥对 ```bash ssh-keygen -t ed25519 -C "deploy@subconverter" -f ~/.ssh/subconverter_deploy ``` 公钥内容复制到 VPS 的 ~/.ssh/authorized_keys。 ## 2. VPS 目录与 Compose 文件 /opt/subconverter/docker-compose.yml ```yaml services: subconverter: image: tropical Cyclone/subconverter:latest # 替换为官方命名或自行 build container_name: subconverter restart: always ports: - "25500:25500" - "8080:80" volumes: - ./base:/opt/subconverter/base environment: - SUBSCR_URL=https://raw.githubusercontent.com/example/example/master/clash.txt networks: - app_net networks: app_net: driver: bridge ``` ## 3. 部署校验 确认 VPS 端口开放后访问 http://vps-ip:25500/sub?target=v2ray&url=... 验证返回。
